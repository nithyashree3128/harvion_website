About the Project

What is Harvion?

A cutting-edge IoT solution for monitoring structural health through vibration analysis and real-time alerting.

Vibration Detection

Precision sensing via MPU6050 accelerometer and piezoelectric transducers to capture micro-vibrations in real time, detecting anomalies before they become critical failures.

ESP8266 Connectivity

Powered by the ESP8266 Wi-Fi module for seamless wireless communication, enabling real-time data transmission to cloud platforms with minimal latency and maximum reliability.

Instant Alerts

Automated SAFE/DANGER classification with instant push notifications, SMS alerts, and email warnings to keep operators informed of structural health status 24/7.

System Architecture

How It Works

An end-to-end pipeline from physical vibration to actionable insight.

Step 01

Sensor Array

MPU6050 accelerometer & piezo sensors capture vibration data from infrastructure surfaces.

Step 02

Arduino Processing

Arduino Uno reads sensor data via I2C/analog, applies filtering, and formats for transmission.

Step 03

ESP8266 Transmission

Wi-Fi module transmits processed data to cloud infrastructure via secure HTTP/MQTT protocols.

Step 04

Cloud Analytics

Data is stored, processed, and analyzed in the cloud with threshold-based alert generation.

Step 05

Live Dashboard

Interactive web dashboard displays real-time graphs, alerts, and system status to operators.
